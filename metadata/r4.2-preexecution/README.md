# R4.2 pre-execution evidence

This directory contains the approved, mechanically validated A/B/C/D feature contracts and the deterministic **planning manifest** for 120 C/D runs. It is separate from all frozen R4.1 evidence.

Nothing in this directory is a model result. A/B are reference-only anchors; C/D have not been trained or evaluated. See `validation-report.json` and `provenance-note-2026-11-22.md`.

The `audit/` directory is a byte-identical durable copy of the reviewed external R4.2 audit. The feature-family manifest is not broadened beyond the approved F2 list and the approved F3 classification of `semantic_timing_relation_count`.
