## Equivalence, redundancy, and confounding

No feature outside F1 generally returns the signed Timing margin or thresholds it. The relation count shares pair selection but not predicate value. F2 shares timestamps/delays; under an immediate-adjacency condition the matched margin equals the response row's inter-event delay, and it equals the global minimum only if that gap is smallest. Thus there is conditional near-equivalence but no general identity.

F3 retains generator-specific structure (trace/event/attempt/retry patterns), so removing direct/generic timing does not remove all construction-related evidence. Count/frequency pairs are algebraically redundant given trace count. Generic Nonce multiplicity can overlap direct cross-attempt sharing under restricted grammars but is not generally equivalent because within-attempt propagation also repeats values.

## Observation horizon

The frozen contract declares prediction unit `one complete canonical scientific trace` and horizon `post_trace_offline` (`trace_features.py:313–320`). All 90 values are consumed as complete-trace aggregates; relation features additionally require post-trace attempt reconstruction. Several counts could be updated on a prefix, but their frozen R4.1 values are final-trace values. They are admissible for R4.1's declared offline horizon and cannot be asserted available for event-time prediction without a different contract.
