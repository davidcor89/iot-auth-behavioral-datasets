# ICDS 2026 historical submission snapshot

This directory is a historical index, not the active scientific namespace.
The immutable annotated tag `icds-2026-artifact-v1.0` and
[`snapshot-manifest.json`](snapshot-manifest.json) identify every file in the
submitted reproducibility artifact by source path, size, and SHA-256.

The repository includes the submitted artifact's dataset, experiment outputs,
figures, tables, notebook, and venue-specific manifests. It does not contain an
exact submitted manuscript source/PDF, reviewer reports, or external
submission-system metadata. Those missing materials are recorded explicitly.

No path in this snapshot tracks future changes to `main`.
